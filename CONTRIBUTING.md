# Contributing to ARIA

Thank you for your interest in contributing to ARIA (Autonomous Research Intelligence Agent)! 
We welcome contributions from everyone, whether it's fixing a bug, adding a new feature, or improving documentation.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork locally**:
   ```bash
   git clone https://github.com/your-username/aria.git
   cd aria
   ```

## Development Environment Setup

Please refer to the `README.md` for detailed instructions on setting up both the Python backend and the React frontend.
Make sure you have both running to properly test your changes.

## Branching Guidelines

- Create a new branch for your feature or bug fix.
- Use a descriptive name for your branch, e.g., `feature/add-new-mcp-tool` or `fix/frontend-rendering-bug`.

```bash
git checkout -b feature/your-feature-name
```

## Making Changes

- Ensure your code follows the existing style conventions.
- If you are adding a new feature, consider updating the `Instructions.md` or `README.md` as necessary.
- Test your changes thoroughly to ensure you haven't broken existing functionality.

## Submitting a Pull Request

1. Commit your changes with a clear and descriptive commit message.
2. Push your branch to your fork on GitHub.
3. Open a Pull Request against the `main` branch of the original ARIA repository.
4. Describe the purpose of the PR and include any relevant issue numbers.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and considerate to all contributors.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub. Include as much detail as possible to help us understand and resolve the issue quickly.
